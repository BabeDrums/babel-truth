# Babel Truth

Shared source of current cross-app truth for the Babel ecosystem.

Babel Truth owns rules that genuinely need to transfer between Babel products: product principles, design foundations, working process, shared semantic contracts, app/repo roles, and major architecture decisions.

It is **not** an app, runtime, universal database, prototype sandbox, or dumping ground for app-specific behavior.

## Core rule

> **One current truth. Clear ownership. History stays in Git.**

Keep app-specific product behavior in the owning app repository. Keep exploratory work in Babel Lab until it earns promotion. Keep superseded current wording out of active authority; use Git history and decision records for history that is actually worth preserving.
